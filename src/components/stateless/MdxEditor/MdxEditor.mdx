# MdxEditor

应用内部的 Tiptap Markdown 编辑器，提供编辑、源码与分栏视图。props 为 initialMarkdown、onChange(markdown)、readOnly，示例与主题 decorators 在同目录 stories。

它通过 Markdown/HTML 转换编辑内容，不执行任意 MDX JSX。转换范围取决于启用的 Tiptap 扩展，不能保证所有格式无损往返。当前不属于 @w.ui/wui-react 发布组件。
