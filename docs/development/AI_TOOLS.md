# 对话与提示词工具

入口为 /#/ai-workbench?view=workspace，或在 AI 工作台切换到「聊天与提示词工具」。

## 日常流程

1. 默认进入「对话」，输入消息试用本地流式交互，支持 Markdown、复制和停止。
2. 打开「提示词工作室」，选择需求梳理、发布计划、故障复盘模板，或从空白开始。
3. 编辑基础字段，按需展开补充信息。预览随草稿更新并可复制。
4. 点击「应用到对话」后，预览才成为系统提示词；未发送的输入保留。
5. 后续编辑不会改变已应用快照；侧栏可查看、返回编辑或移除。移除不会被自动生成逻辑写回。
6. 草稿替换、清空与消息清空可撤销；清空消息不清空输入框。

## 对话与联网检索

当前对话为本地演示，没有连接通用模型或外部服务。响应明确说明演示边界，并使用当前问题与已应用提示词；演示步骤不是模型的真实内部推理。

「打开 Tavily Playground」进入[真实联网检索](./TAVILY_PLAYGROUND.md)。旧联网开关混用会话与请求语义，现统一到 Playground；切换页面保留已有工作，不自动发送查询。

## 调试与保存

「调试工具」抽屉提供演示间隔、片段大小、演示步骤、请求指标和最近事件；事件不包含消息正文、原始分块或错误原文。

设备保存默认关闭。开启后只按当前项目、账号与租户保存提示词和设置；关闭会删除保存内容。消息、未发送输入与事件只在内存。存储不可用时显示提示，仍可继续使用。

旧版共享缓存不自动迁移。从调试抽屉主动导入时只读取有效提示词字段，支持撤销，也不静默删除旧缓存。
