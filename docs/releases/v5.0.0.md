# Pro React Admin v5.0.0

v5 将工程从展示模板推进到可扩展的企业管理应用：统一项目注册、模块路由/菜单/权限、构建与部署入口，提供精简企业应用、真实租户/RBAC 服务、持久化资源管理和事务审计，以及完整后台、多项目和微前端演示。

## 主要变化

- 企业 API 使用单实例 Node 24 与持久卷 SQLite，支持真实账号登录、用户/角色 CRUD、租户隔离、会话撤销、权限提升保护、最后管理员保护及同事务追加审计。
- 应用 store、会话和资源缓存按身份范围隔离，支持请求共享、取消、TTL 和写入失效，避免退出/切换租户后复用旧响应。
- 注册表驱动项目开发、构建、预览、清理与部署，提供脚手架、路径别名与导入边界检查。Shell/Remote 通过 manifest、共享依赖和协议契约验证加载。
- 修复 Storybook 开发构建的 `$RefreshSig$ is not defined`，隔离应用 Babel Refresh 配置，补齐主题、Router、Ant Design、Tailwind、Less Modules 和 SVG 支持。
- 157 个 UI 入口有源码旁 stories：12 个公开 WUI 组件、2 个共享 UI、139 个 Stateless 入口和 4 个 Stateful 入口。新增源码覆盖、类型与构建索引检查。
- GitHub Pages 支持 `all/default/enterprise/mfe/multi/storybook`，正确处理仓库子路径、自定义域名和 HTTPS Remote 地址；独立 Vercel Storybook 使用可复用的静态预构建产物。
- 重建快速上手、架构、企业服务、权限、组件包发布与部署文档，并更新 README 的预览和命令入口。

## 升级与边界

工程开发要求 Node.js >=24.15.0 且 <25、pnpm 11.5.2。UI 包要求 React 19、Ant Design 6 和兼容的 framer-motion，公开导出以 library-contract 为准；旧版应用展示组件不自动成为 v5 npm 导出，升级前核对 subpath 和 peer dependencies。

真实 API 与静态演示明确分开。GitHub Pages/Vercel 的临时文件系统不运行本实现的持久 SQLite 服务；真实模式需外部持久 API 和 HTTPS/CORS。公开演示使用浏览器 mock，不等同真实权限隔离或持久账号管理。

附件中的 UI tarball 经过构建、包契约、ESM/CJS 消费及体积门禁。GitHub Release 不执行 npm publish；npmjs 发布状态和 2FA/Trusted Publishing 认证独立核验。应用标签为 `v5.0.0`，UI 包标签为 `wui-react-v5.0.0`。

本地 Storybook 静态构建、全部 Pages 场景及部署路径/Remote 容器检查已通过。交互和线上状态以实际浏览器/Actions 结果为准，完整分阶段记录见当时版本的 [VALIDATION.md](https://github.com/wkylin/pro-react-admin/blob/v5.0.0/docs/VALIDATION.md)。全仓 strict、SSO、多组织成员关系、分布式服务与运行期插件仍是后续演进工作。
