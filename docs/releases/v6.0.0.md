# Pro React Admin v6.0.0

本次版本把 Webpack 与 Vite 收敛到同一份应用、Storybook 和组件包源码，并将项目概览、开发验证和交付路径展示在应用内。应用与 `@w.ui/wui-react` 的版本均为 6.0.0；两者分别使用 `v6.0.0` 和 `wui-react-v6.0.0` 标签发布。

## 主要变化

- 统一项目注册、构建目录、浏览器环境变量入口和开发命令，可选择 Webpack 或 Vite 构建应用、Storybook 和组件包。
- 新增公开项目概览与登录后首页的工程导览，连接业务场景、源码目录、测试、构建产物和部署文档；修复两个入口的纵向滚动。
- 将 GitHub 登录接入演示账号流程，并整理本地 Tracking API、环境变量与 Vercel 同源回调配置；企业租户登录仍使用独立身份与权限流程。
- 整理单元测试、端到端测试、覆盖率、报告、构建统计和部署文档；Storybook 与组件包分别说明本地开发、验包及发布去向。
- 增强企业 API 的数据库迁移、锁与恢复操作，完善模块契约、管理后台标签页和通知交互。
- 改进 InteractiveBook 的翻页与封面效果，使用项目内的翻页引擎，并增强组织图、媒体示例及 Pages 导航。
- Vite 组件包构建不再复制应用的 `public/` 文件，包校验会拒绝意外静态资源。

## 升级与交付

- v6 应用模块的宿主兼容范围已更新；自定义业务模块需要核对其 `compatibility.application` 是否包含 `6.0.0`。业务模块契约仍为 v2。
- `@w.ui/wui-react` 保持 12 个公开组件及现有 ESM、CommonJS、类型和样式入口。升级消费端前核对 [peer 范围及导入方式](../../NPM_README.md)；应用内部组件不会自动成为 npm 包导出。
- `v6.0.0` 触发应用 GitHub Release，附带经过验证的组件包 tarball 与校验和；它不会自动发布 npm。独立的 `wui-react-v6.0.0` 标签触发 npm 发布工作流。两种发布分别检查 GitHub Release 与 npm registry 的最终结果。
- GitHub Pages 承载静态应用与 Storybook；GitHub 演示登录依赖 Vercel 同源函数，企业持久数据依赖独立 API。
