# Pro React Admin v5.1.0

本次更新把技术架构与 Webpack 页面调整为当前工程的真实实现，修复 Storybook 组件预览，并改善管理页面编辑回填与顶部头像样式。应用版本和 GitHub Release 附件中的 `@w.ui/wui-react` 包版本均为 5.1.0。

## 主要变化

- 重构技术架构页，展示应用、共享 UI、平台服务、企业 API、构建链路及部署目标之间的关系。
- 在 Webpack 页面补全项目构建模式、项目注册表、模块联邦、组件库打包和交付路径。
- 编辑用户与角色时展示已填写的数据。
- 修复动画、图表、滚动、媒体等组件的 Storybook 预览与交互，并为视频预览加入本地封面。
- 单独定义顶部头像尺寸，保留其他工具图标的 24 像素规格。
- 通过 GitHub Pages 同时发布默认应用、企业和多项目演示、微前端及 Storybook。
- 修复干净 checkout 中的文档校验，直接检查组件包 README 的源文件，避免发布前依赖尚未生成的打包文件。
