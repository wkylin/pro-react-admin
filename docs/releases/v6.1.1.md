# Pro React Admin v6.1.1

本次发布让 Storybook 中的组件说明更容易查阅，并重排 npm 包首页。应用与 `@w.ui/wui-react` 的版本均为 6.1.1；应用 Release 与组件包分别使用 `v6.1.1` 和 `wui-react-v6.1.1` 标签。

## 主要变化

- 所有 Storybook 组件文档统一展示适用场景、交互预览、使用注意和 Props 含义；已有手写文档保留组件专属的详细示例，并使用同一展示结构。
- npm 包首页先说明安装、最短用法和导入入口，再列出 12 个基础组件、7 个扩展组、按需依赖和关键使用边界。
- 补充 Storybook 文档覆盖与 Props 说明的检查，便于在新增或修改组件时发现缺漏。

本次组件包更新以文档和示例为主，公开运行时 API、导入路径及 peer 版本范围保持兼容。完整用法见 [npm 包说明](../../NPM_README.md) 和 [Storybook](https://wkylin.github.io/pro-react-admin/storybook/)。
