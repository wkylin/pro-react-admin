# 后台石墨灰主题重构设计

日期：2026-11-05  
状态：视觉方向 A 已选定，设计待批准  
项目：pro-react-admin

## 1. 目标与范围

将现有后台的暗色模式统一为简洁的石墨灰视觉，并提供相应的浅色主题。保持 Ant Design 6、现有页面与功能，通过主题令牌、布局样式及页面颜色适配完成重构。

用户已选择 **A：Studio Admin / Shadcn 式石墨灰、细边框和克制的蓝色**。本设计中的具体色值、字体和控件尺寸是实施建议，批准后作为验收依据。

本轮完成：

- 主布局、导航、面包屑、Chrome 式页签、底部操作区的主题统一。
- AntD 按钮、输入框、选择器、表格、分页、卡片、表单、提示、标签与浮层的统一。
- 管理列表、表单示例及部署指南等页面的颜色冲突适配。
- 浅色、暗色、独立深色导航、自定义主色、紧凑模式及手机布局的兼容检查。

专用图表、3D 展示、代码高亮和插画保留自身的内容配色；其外围控件和基础文字参与主题适配。使用代表页面与共享组件进行覆盖，不把所有演示页面重新排版。

## 2. 已确认的问题

### 浏览器实测

- 暗色部署指南的背景为 `rgb(246, 248, 251)`，标题为 `rgb(245, 245, 245)`，存在浅底浅字。
- `--wui-bg-base` 在运行时未定义，部署指南中四处引用因此使用浅色回退值。
- 暗色侧栏沿用深蓝色，内容区、浮层和自定义页面采用不同灰阶，视觉层次不统一。

### 代码审计

- `src/theme.tsx` 把主色的普通、悬停和按下状态设置为相同颜色；交互状态区分不足。
- `ProSecNav` 以行内样式设置选中背景和文字，会覆盖统一组件主题的结果。
- `reset.css` 的自定义颜色与 ConfigProvider 主题分开维护，缺少统一映射。
- 默认滚动进度条使用彩虹渐变，与本次选定风格不协调。
- `renderApp` 中的 AntD App 位于主题 ConfigProvider 外侧。当前反馈实例由外层 App 获取；消息和确认框的主题继承需专项验证，必要时在主题内建立反馈作用域。

截图基线保存于本次调研的临时目录，包含用户列表、用户弹窗和部署指南。结构风险与浏览器实测分开记录，不把尚未验证的反馈问题当作既成缺陷。

## 4. 视觉基础

### 色彩与语义

建立一个供 AntD 主题与页面 CSS 变量共同使用的语义色板。页面不各自定义暗色背景。

| 角色           | 暗色基准  | 浅色基准  |
| -------------- | --------- | --------- |
| 画布           | `#181818` | `#f5f6f8` |
| 基础表面       | `#1f1f1f` | `#ffffff` |
| 浮层、抬升表面 | `#272727` | `#ffffff` |
| 普通边界       | `#313131` | `#e5e7eb` |
| 主要文字       | `#f5f5f5` | `#171717` |
| 次要文字       | `#c2c2c2` | `#525f70` |
| 辅助文字       | `#a3a3a3` | `#667085` |

操作色沿用用户设置的主色，并为文字、实色按钮、悬停、按下和焦点推导合适的颜色。默认主色仍为蓝色。选中导航使用低饱和度背景与清晰文字；避免大面积明亮蓝块。

成功、警告、错误和信息颜色保留语义，并配合文字或图标表达状态。普通文字对比度至少 4.5:1，关键控件和焦点标识至少 3:1；禁用态与装饰边界按其语义验收。

### 字体与几何

- 使用本地提供的 Geist 拉丁字体，中文使用系统中文字体回退；只引入所需字体资源，不依赖运行时字体 CDN。
- 标准正文、表格、按钮为 14px / 20px；辅助信息为 12px / 16px；主要页面标题为 24px / 32px。字体以 400、500、600 为主。
- 页签文字继续保持一致字重，避免切换时发生宽度抖动。
- 常规控件高度以 36px 为基准；紧凑模式保持有效，使用更紧凑的尺寸。手机主要工具按钮保留适合触控的目标范围。
- 控件圆角以 8px 为主，内容卡片和弹层以 12px 为主。布局间距使用 8、12、16、24、32px 的现有尺度。
- 用灰阶、边界和有限阴影表达层次；不增加背景渐变或装饰动画。

字体资源的版本、许可与实际体积在实施时核验，随改动记录；不增加新的组件库。

## 5. 布局与导航合同

- 主 Header 调整为 56px，工具按钮使用更简洁的边界与悬停反馈；保留原有入口及操作。
- 面包屑单行高度保持 40px，保留细线箭头；窄屏长路径沿用可容纳内容的策略。
- Chrome 式页签保留外形、刷新和关闭按钮、溢出菜单、键盘操作及缓存行为。活动页签与内容表面相接。
- content 外层内边距继续为 0。页面内部的表单、卡片、表格单元格按各自布局留白。
- 侧栏展开宽度 208px、收起宽度 80px；多级菜单每级缩进 8px，保留箭头区域与完整名称提示。
- 暗色侧栏改用中性灰阶。独立深色导航在浅色页面中仍保持可读。
- 底部展开/收起按钮继续为 40px 高、18px 图标，保留居中、焦点与悬停状态。
- 保留滚动进度功能，默认进度颜色跟随主题操作色。
- 保留品牌标识与水印功能；水印的明暗对比不得遮挡主要数据。

## 6. AntD 组件合同

| 组件                                | 重构要求                                                                             |
| ----------------------------------- | ------------------------------------------------------------------------------------ |
| Button                              | 主要、普通、文字、危险、禁用、加载、悬停、按下与焦点状态可区分；根据背景计算文字对比 |
| Input / Select / DatePicker         | 统一高度、边界和表面；placeholder、选中、聚焦、错误、禁用与下拉面板适配主题          |
| Table / Pagination                  | 表头、表体、悬停行和选中行分层；保留排序、筛选、分页、空态、加载与移动显示           |
| Card / Form                         | 内容间距与标题层级统一，避免重复描边；保留校验和提交流程                             |
| Alert / Tag / Badge                 | 保留状态含义，降低非关键提示的视觉重量，保持文字可读                                 |
| Modal / Drawer / Dropdown / Tooltip | 表面、遮罩、边界、关闭按钮和焦点一致；浮层通过正确主题作用域渲染                     |
| Message / Notification / 确认框     | 核对上下文来源，避免主题切换后反馈仍采用默认样式                                     |
| Menu / Layout / Tabs                | 使用共享令牌，移除阻碍主题生效的局部固定颜色                                         |

优先使用 ConfigProvider 的全局和组件令牌，以及 AntD 6 的语义样式接口。确需 CSS 的布局状态限定在对应组件，不扩散高优先级全局覆盖。

## 7. 实施结构

- `src/theme/`：维护主题色板、AntD 配置生成和相关对比度逻辑。
- `src/theme.tsx`：消费统一配置，保留 locale、prefix、compact 设置和稳定的 Router 实例。
- `src/theme/hooks.tsx` 与全局样式：保持用户偏好持久化、系统主题监听和 CSS 变量同步。主题切换不能重建业务路由或清空页签。
- `src/app/layouts/`：让 Header、导航、页签和侧栏操作区消费统一主题。
- `src/shared/ui/FixTabPanel`：保留零内边距，统一默认进度颜色。
- 部署指南、管理工作区、页面示例等：收口缺失变量和固定颜色；不重写业务组件。
- 主题内的反馈作用域与消息桥接由实施者选择最小可靠方案；保留其他应用入口使用 `renderApp` 的能力。

具体文件拆分与令牌名称由实施者决定。CSS 初始回退样式可以存在，但实际运行中的 CSS 变量和 AntD 配置必须来自同一语义映射。

## 8. 分步落地

1. 统一色板、AntD 基础组件主题与 CSS 变量；修复浅底浅字和主色状态重复问题。
2. 调整应用框架、导航与页签，使灰阶和状态连贯。
3. 适配管理列表、表单和部署指南等代表页面；核对浮层和反馈。
4. 完成明暗、独立导航主题、自定义主色、紧凑模式与手机验收。

本轮最终交付包含以上步骤，不能仅交付一个独立预览页面。

## 9. 功能与兼容边界

- 路由、权限、登录、API、CRUD、国际化、主题设置项及其存储隔离保持原合同。
- 不替换 React、AntD、路由器或现有表单、表格业务实现。
- 不修改后台接口，不增加业务轮询和额外数据请求。
- 保留已有工作树中的页签、面包屑、多级菜单及 content 调整，并在此基础上合并主题改动。
- 全站自定义主色与紧凑模式仍可使用；不能仅让默认蓝色好看。
