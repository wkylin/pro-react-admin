# 工作台第二轮优化

## 意图与范围

继续上一轮 Studio Admin 对标，优先交付导航聚合、常用业务页面结构统一、通知编辑闭环。保留上一轮仪表盘和所有业务权限。真实仪表盘的数据来源另行确认，独立检查现有后端是否存在客户、订阅及收入口径。

## 方案选择

- 逐页独立调整视觉：短期改动小，但重复样式会继续分叉。
- 共用业务页面容器和工具条，再迁移现有页面：本轮采用，统一标题、边距、内容间距和手机换行，业务逻辑保持在原模块。
- 一次重建布局和全部 CRM：范围过大，无法用一轮完整验证，暂不采用。

## 设计

1. 导航以业务入口优先，仪表盘紧邻首页。组件交互、可视化、AI、媒体、工程技术各自收组，保留全部叶子路由与权限；全局搜索仍能找到组内页面。默认运行时根菜单目标不超过 12 个，空分类随权限过滤。
2. 新增共享 `BusinessPage` / `BusinessToolbar`。24px 桌面边距、16px 手机边距，24/32 标题，语义主题色；标题、说明与操作有固定结构。优先迁移仪表盘、组织管理、页面模板及通知。
3. 通知支持创建、编辑、表单校验、保存反馈、详情、删除、已读状态及筛选导出。操作遵守现有 permission code，去掉 Ref 设置标题和重复 query 演示入口。
4. 通知 store 保留按 Provider 隔离和 `ephemeral` 卸载清理契约，不引入未经设计的跨账号本地持久化；界面明确演示与刷新重置。
5. 沿用现有技术栈和主题，不增加依赖。中英文完整，手机宽度 390px 无页面横向溢出；表格在自身容器内滚动。
6. 用户已选择业务仪表盘继续使用演示数据，先完善体验。管理概览仅复用既有 provider 的成员/角色 `total`，按当前读取权限显示，不新增客户或收入接口。

## 验证

菜单分组和权限过滤测试、通知 CRUD 和 Provider 隔离测试；类型、格式、路由、国际化、导入边界及文档检查；浏览器验证搜索组内入口、通知创建编辑及列表/抽屉/详情一致、权限视角、明暗主题和手机布局。现有用户管理和页面模板流程需保持可用。

## 已完成

- canonical 根菜单从 41 项压至 12 项（默认应用因权限/可用性过滤显示 11 项），最长层级从 5 层降至 3 层；54 个原叶子入口全部保留，另外显式加入通知及原被嵌套掩盖的 Vue 页面。业务入口前置，演示归入五组。
- 全局搜索显示“工程与技术 / 构建工具”等译后分组路径，保留模糊/拼音匹配和权限过滤；移除了结果按钮取消键盘轮廓的样式。
- `BusinessPage` / `BusinessToolbar` 统一仪表盘、管理资源页、管理首页、页面模板和通知页的标题、说明、操作区与间距；删除三套重复容器样式。表格隐藏测量行的焦点修复集中到共享层。
- 通知已实现创建、编辑、必填及长度校验、保存反馈、未保存草稿确认、详情、已读及删除。保留 Provider 内存隔离与卸载清理，中英文提示明确刷新重置。
- 通知筛选、排序与分页可通过 URL 恢复，CSV 只导出筛选范围或该范围内选中记录，并转义公式前缀。新建成功回第一页显示新记录；缓存详情再激活会标已读，隐藏详情允许设为未读。
- 通知种子按每个 store 当前时钟生成较早记录，避免固定未来样本挤走新消息。
- 管理首页增加“可见成员数 / 可见角色数”，只在各自 read 权限下使用 `pageSize: 1` 请求的服务端 total；独立加载/错误/重试、资源订阅刷新与卸载中止均已覆盖。
- 修复查询表格的开发模式 StrictMode 重放中止首次请求、但表格只自动加载一次所导致的空列表；真实卸载仍会中止，迟到结果不更新页面。

## 验证记录

- Jest：12 组，72 项通过，覆盖导航/搜索、通知模型与 CSV、管理总数、查询请求生命周期、仪表盘、权限及模块隔离。
- Playwright：7 条独立流程通过，涵盖三条原有表单流程、抽屉到详情、通知 CRUD/校验/筛选导出/缓存已读、只读权限，以及手机取消/保留/放弃草稿。使用临时配置访问本地 Vite 预览，未修改既有表单断言。
- 应用/E2E 类型检查、修改代码 ESLint、Stylelint、Prettier、路由、国际化、导入边界和文档检查通过。
- 浏览器核实分组导航与搜索，通知桌面/390px 明暗主题和手机编辑器；390px 页面 scrollWidth 为 390px，弹窗宽度为 374px。
- 独立审查发现的创建后记录被筛选隐藏及缓存已读问题均已修复并复核；对应浏览器回归通过。

## 仍待独立迭代

业务仪表盘按用户选择保留演示数据。CRM 需先明确客户、负责人、阶段与跟进记录的模型；订阅收入需明确账单来源、币种、时区及实收/确认收入等口径。现有成员和审计数据不能替代这些业务实体。本轮没有执行生产部署。
