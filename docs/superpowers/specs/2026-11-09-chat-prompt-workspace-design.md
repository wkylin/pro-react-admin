# 对话与提示词工作区重构

## 用户决定

用户认为 Chat & prompt tools 功能杂乱，选择「日常使用：对话、提示词分区，调试收进抽屉」。沿用产品工作室方向和现有语义主题，减少首屏工程说明、指标卡片与嵌套面板。

## 方案与行为

- 保留开发实验台会继续混杂主次；提示词单一主流程会弱化对话。采用用户选定的双分区，调试工具按需打开。
- 默认进入对话。消息复制、Markdown、停止与清空保留；切换分区不重新挂载 SmartChat，不覆盖未发送输入。
- 提示词区提供三个双语模板、五项基础字段、三项折叠补充字段、预览与复制。编辑仅更新草稿，点击应用才更新对话的系统提示词。
- 移除已应用提示词不会被编辑器自动填回；替换/清空草稿及消息清空提供撤销。
- 对话明确为本地演示，不冒充通用模型。真实联网检索统一进入 Tavily Playground，移除不能复用其内存连接的旧开关。
- 参数、最近事件与耗时指标进入抽屉；不显示默认百分百健康度或主流程架构说明。
- 设备保存默认关闭。开启后按项目、账号、租户保存提示词与设置，关闭即删除；消息、输入与事件不保存。
- 旧版共享草稿保留，仅用户主动导入时才进入当前账号，不自动迁移未知归属的内容。

## 设计与验证

沿用 BusinessPage、Geist、语义主题色、12px 面板圆角、24/16px 间距。对话优先，提示词侧栏次要；窄屏依次排列，编辑与预览改为单列。不增加渐变与重阴影，保留焦点与减少动效支持。

验证缓存隔离与校验、事件脱敏、演示流完成/取消清理，以及浏览器分区、应用快照、输入保留、移除、保存、身份切换、主题和滚动。回归 Playground，自动验证阻断真实 AI 请求。
