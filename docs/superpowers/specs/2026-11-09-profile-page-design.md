# 个人资料页完善

用户要求把 `/profile` 从静态 codeString 展示完善为实际个人资料页。现有账号、角色、主题和语言能力均复用，不新增身份接口或生产资料写 API。

## 选择与范围

比较了只重排静态履历、接入管理员用户写接口、基于当前账号提供本地展示资料三种方式。采用第三种：静态作者履历不代表当前用户，管理员 API 也不是个人资料 API。开发者选择在已有授权内完成当前账号摘要、可编辑本地展示资料和实际生效偏好。

- 使用 `useAuth` 的姓名/账号/邮箱/头像，`usePermission` 的用户 ID 与角色；缺失信息显示未提供，不虚构工作经历、项目数或登录历史。
- 展示资料包含显示姓名（1–60 字）、职位（最多 80 字）、部门（最多 80 字）、所在地（最多 80 字）、简介（最多 280 字）；除姓名外初始为空。
- 通过编辑弹窗修改，保存校验后即刻更新本页；取消已填写内容需确认，选择继续编辑保留草稿。
- 使用带版本的 localStorage 记录，按项目、登录来源、租户和账号隔离；不保存令牌、登录邮箱或权限。刷新可恢复同账号的展示资料，切换账号不串数据。
- 明确说明本地保存范围。读存储异常提供提示并使用账号默认值；写入失败保留草稿，不显示保存成功；异常 JSON/版本/字段回退默认资料。
- 主题（浅色/深色/跟随系统）、语言（中文/English）、紧凑布局复用已有设置，立即生效。
- 仅显示当前用户可访问的工作台/通知/权限入口；登录验证器入口仅在真实 Enterprise 会话且已有路由可访问时出现。不伪造安全状态，不展示任何 token。
- `/profile` 的注册范围和 `profile:read` 策略保持不变，不自动新增 Enterprise 入口，不修改全局账号信息或授权。

## 布局与状态

复用 BusinessPage 和 Geist 字体，左侧账号身份面板，右侧展示资料与偏好设置。手机变为单列；标题 24/32px，分区标题 18/28px，正文 14/20px，辅助文字 12/16px；页面与面板间距 24px，手机 16px，内部间距 8/12/16px。

使用现有 `--wui-bg-surface`、`--wui-bg-subtle`、`--wui-border`、`--wui-text-primary/secondary/muted` 和主题主色。表单使用共享控件的标签、焦点与校验状态，支持键盘和明暗主题，不引入背景渐变或新的字体/组件依赖。

账号/权限加载时显示骨架；无账号时给出登录入口，权限读取失败提供重试。长姓名、邮箱、角色和简介可折行。简介空态提示补充自己的介绍，不显示原作者履历。

## 验证

领域检查：边界长度、空白、存储恢复、损坏和不可用存储、身份隔离。浏览器验证：账号信息、本地资料保存/刷新恢复、取消确认、账号切换、主题/语言/密度及 390px 布局。执行受影响文件 lint/format、应用/E2E 类型、i18n、文档与路由契约检查，独立审阅后交付本地改动。
