# Chat Room Implementation Plan

> **For agentic workers:** 使用 subagent-driven-development 分别实现 API/模型、实时通道与界面，统一集成和独立复核。用户已授权复用既有后端，持续实施；不修改外部后端仓库，不自动提交。

**Goal:** 交付与现有 Chat Platform 兼容的独立群聊工作区。

**Architecture:** 独立 chatRoom feature 负责模型、API、XMPP 与界面状态；默认路由引用页面。旧 secureCommunication 仅复用地址校验与 loader，保持加密工具行为。

**Tech Stack:** React/TypeScript、Ant Design、CSS Modules/Less、@xmpp/client、Jest、Playwright。

**Spec:** [设计](../specs/2026-11-09-chat-room-design.md)

## Global Constraints

- 不新增依赖，不持久化凭据或聊天内容，不修改外部服务或原加密协议。
- 消息必须来自真实后端协议；不伪造私聊、在线人数、typing、附件或送达/已读回执。
- 明暗主题、中英文、窄屏、键盘、输入法与 reduced-motion 可用。
- 相关测试使用受控接口/协议替身，不向真实房间发消息。

## Review Focus

- 取消登录时临时会话创建晚返回，必须清理且不能污染新连接。
- 快速切房时加入 ACK、实时和历史乱序，按服务端 ID 去重并保持正确房间。
- deleted/removed 及 AES JSON 内容不得作为普通消息原文显示。
- 断线与身份切换须清除缓存/草稿和停止重连，隐藏页不得错误清零新消息。
- 发出消息期间继续编辑、中文输入法 Enter，不能误发或丢新草稿。

## 完成与验证记录

- 已交付独立 `/chat` 页面，沿用既有 Chat Platform REST/XMPP 后端，原加密实验室及前轮 Tavily 改动保留。
- 7 组相关 Jest 测试共 123 项通过，包含模型/API、实时通道、工作区、原加密通道、导航与权限。
- 10 条 Playwright 流程全部通过；真实客户端协议覆盖 SASL/bind/MUC/echo、历史去重、草稿与输入法、迟到历史、取消与账号隔离、手机明暗主题。
- 特别回归真实 WebSocket clean close 自动重连与漏消息补拉、重入拒绝/超时不恢复可发送、跨房间迟到发送错误隔离、补历史后切房滚动位置。独立复核确认修复。

- 1440px 桌面与 390px 手机已目视检查，支持房间详情和手机返回，页面无横向溢出。普通演示账号的既有 crypto 权限可进入新聊天室。
- 测试拦截所有聊天室 REST/WebSocket，未在公共服务创建测试会话或发送真实消息；本轮没有修改外部后端或新增持久化凭据。
