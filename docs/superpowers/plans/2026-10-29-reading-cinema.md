# 阅读与电影页面

## 目标

- 在主应用新增可从菜单进入的阅读与电影路由。
- 阅读页提供可直接打开的原创短篇书架，使用 `InteractiveBook` 翻页阅读。
- 电影页提供真实可观看的 Blender 开放电影片单，使用 `SmartVideoPlayer` 播放，并准确标识 4K 可用性。

## 设计与内容参考

- [Literal](https://literal.club/) 的个人书架与阅读状态：参考书籍陈列与选书路径，改为适合本项目的四本原创短篇。
- [MUBI 正在放映](https://mubi.com/en/us/showing) 的策展片单：参考大幅剧照、影片信息层级与放映氛围。
- [Blender Studio 电影目录](https://studio.blender.org/films/)：选取开放电影；站内播放文件来自各影片的 Wikimedia Commons 文件页，并在放映弹层列出来源与授权。

## 实施

1. 用独立数据文件维护书籍和影片，给封面与影片缩略图提供本地资源。
2. 构建书架与放映室页面，处理弹层焦点、Escape、选片、关闭后的播放停止和移动端布局。
3. 注册懒加载路由、菜单策略与中英文文案。
4. 运行路由校验、类型检查与页面交互检查，修复发现的问题。
